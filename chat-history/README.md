# Архив чатов разработки

Сырые транскрипты сессий Claude Code (JSONL, каждая строка — событие).
В git не коммитятся — это сырьё, а не знание: всё, что из них следует
для проекта, перенесено в `CLAUDE.md` (раздел «Состояние проекта»),
`docs/*.md` и сообщения коммитов. Правило проекта: смену сессии переживает
CLAUDE.md, а не чат.

| файл | период | что было |
|---|---|---|
| `2026-08-04_фазы-1-5.jsonl` | 04–12.08 | фазы 3–5: PositionAdvisor, TavernAdvisor, живой режим, оверлей |
| `2026-08-12_оверлей-патч-правила.jsonl` | 12–13.08 | запуск оверлея у игрока, патч 248348, фикстуры part4–8, правки правил по обратной связи, тринкеты, сила героя, тёмный дар |

Новая сессия ничего отсюда не читает: контекст ей даёт `CLAUDE.md`
автоматически. Возобновить именно СТАРЫЙ разговор можно командой
`claude --resume` (выбор из списка) — но для работы это не нужно.
