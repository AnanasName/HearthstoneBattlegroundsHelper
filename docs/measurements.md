# Замеры батареи

Файл генерирует `npm run battery` после полного прогона на чистом дереве
и перезаписывает его целиком — руками сюда не пишется.

Полного прогона ещё не было: числа до 15.09.2026, снятые по одному скрипту,
с разборами — в [docs/quality.md](quality.md). Какие партии не входят
в список замеров и сколько коммитов прошло с последнего прогона, говорит
`npm run battery -- --status`.
