# Разбор сообщений игрока

Сообщения приходят пачкой после партии (2–4 за раз) и всегда проходят одни
и те же стадии. Стадии разведки отданы субагентам с дешёвыми моделями:
тикеты и сторож — `haiku`, фактура из логов — `sonnet`. Главная сессия
тратится только на то, ради чего она нужна: **какое это правило и какой
ценой**.

## Когда не сюда

- Партия ещё не вырезана в фикстуру → сначала навык `fixture-markup`.
- Игрок просит замер или батарею → это отдельный прогон в своём worktree,
  разбор тут ни при чём.
- Одно сообщение, ответ на которое уже виден целиком → просто ответь.
  Конвейер окупается от двух тикетов.

## Порядок

### 0. Привязка (главная сессия, дёшево)

Назови партию и кадры. Есть `partN` в `data/fixtures/`? Есть скриншоты
в `data/screenshots/` — плоско или папкой со временем партии
(`2026-09-22_1454/`; номера `partN` игрок на момент съёмки не знает, папку
переименовывает тот, кто вырезал фикстуру)? Если партия не названа и кадра
нет — спроси раньше, чем что-то запускать: без момента разбор превращается
в гадание.

### 1. Тикеты — один вызов `hsbg-triage` на ВСЕ сообщения сразу

Отдай ему текст сообщений дословно плюс: имя партии, список кадров, номер
билда. Вернёт по тикету на сообщение: класс (A не читает / B не говорит /
C расхождение / D нет фактуры / E похоже на закрытое), момент в обеих шкалах
ходов, предмет спора, ключевые слова.

Сообщения не пересказывай — отдавай как есть: формулировка жалобы это
фактура, а не шум.

### 2. Сторож и фактура — параллельно, по всем тикетам одним сообщением

- `hsbg-precedent` на каждый тикет: не спорит ли это с D-решением, не лежит
  ли в `deferred.md`, не записано ли в `next-steps.md`.
- `hsbg-evidence` на тикеты классов A и D: есть ли фактура в логах и что
  говорит снапшот карт.
- Класс C (расхождение) фактуры не требует — его считает прибор:
  `npm run review -- partN [--turn=N]`. Запускай его сам в фоне, пока идут
  агенты.
- Класс B (не говорит) — ни того, ни другого: проверь `reason` через
  `npm run fixture:at -- partN ЧЧ:ММ:СС` и смотри, что из него видно
  на экране.

Вердикт **СПОРИТ** от сторожа — стоп. Дальше решает игрок, а не правка.

### 3. Решение (главная сессия, здесь не экономим)

На руках: тикет, вердикт сторожа с цитатой, строки лога. Теперь —
формулировка правила: что именно читаем, чем платим, где ставим порог.
Это не отдаётся субагенту: цена решения и его место среди 275 прежних
держатся на вкусе, а не на поиске.

Проверь себя двумя вопросами проекта: правило читает **текст карты или тег**,
а не догадку? Порог взят **замером**, а не на глаз? Если замера нет — так
и напиши в журнале («замером не подтверждено»), это законный статус.

### 4. Правка с тестом

TDD: сначала падающий тест на фикстуре со ссылкой на строки лога, потом код.
Тест, читающий `Power.log`, идёт в проект `fixtures`; долгий цикл по событиям
отдаёт поток через `createBreather()`.

### 5. Проверка

`npm run check` — типы, линтер, быстрый набор. Файл своей правки —
`npx vitest run <файл>`. Полный `npm test` — перед пушем.

### 6. Запись

Запись о партии целиком — в `docs/journal.md` с якорем `j-MMDD-N`; новое
решение — пункт в `docs/decisions.md` с якорем `<a id="dNNN"></a>` и строкой
в индексе; в `CLAUDE.md` — строка в «Последних записях» и, если сдвинулись,
числа «Текущего состояния». Больше в `CLAUDE.md` ничего: его размер держит
тест `test/docs/claudeMd.test.ts`.

Числа замеров в документацию не переписываются — только вердикт и ссылка.

### 7. Коммит

По явному списку путей (`git add <файлы>`, никогда `-A`): в дереве работают
соседние сессии.

## Что субагентам не отдаётся

- **Формулировка правила и его цена.** Разведка — их, решение — твоё.
- **Замеры.** `battery`, `validate:*`, `spike:*` запускаются из главной
  сессии и только в отдельном worktree, если это батарея.
- **Правка общих файлов.** `CLAUDE.md`, `docs/journal.md`,
  `docs/decisions.md` пишет одна рука. Перед правкой проверь, не трогает ли
  их сосед: `git diff --stat` и `ls -l --time-style=full-iso` по этим файлам,
  `ListAgents` — кто ещё в дереве.

## Зачем так

Логи фикстур по 25–40 МБ, снапшот карт 41 МБ, `docs/decisions.md` 420 КБ.
Разведка по ним стоит контекста, а не ума: её результат — пять строк цитаты
из миллиона. Субагент платит за чтение своим окном и возвращает эти пять
строк; главная сессия остаётся с фактами вместо дампов, и до правила
доходит с чистым контекстом.
